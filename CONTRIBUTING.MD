# Contributing

Thank you for helping improve this reference.

## Reporting an issue

Please open a GitHub Issue and include:

- The relevant section
- The R operation
- The current Python translation
- The proposed correction
- Any error message or supporting documentation

## Submitting a change

1. Fork the repository.
2. Create a new branch.
3. Make and verify your changes.
4. Submit a pull request.
5. Explain why the revised translation is more accurate or useful.

## Style

- Label R and Python examples explicitly.
- Use `=` for assignment in R examples.
- Include required imports.
- Prefer readable statistical code over unnecessarily condensed code.
- Explain important differences in defaults or interpretation.
- Do not include homework answers, private data, or copyrighted course materials.
