# coursework/

Your own course notebooks and scripts go here. Start from a template:

```powershell
Copy-Item templates\exercise.ipynb coursework\hw1_q1.ipynb
```

**Everything in this folder except this README is git-ignored by default**
(see `.gitignore`). Graded answers therefore can't be pushed to a public
repository by accident. If your repository is private and you want to
version your work, delete the `coursework/*` lines from `.gitignore`.
