# Security policy

This repository is an educational toolkit and contains no services or
credentials. If you find a security problem, for example in the Codespaces or
Binder configuration, please report it privately with GitHub's **Report a
vulnerability** button (Security tab), rather than in a public issue.

## Using this toolkit safely

* Never commit patient data, other identifiable information, API keys, or
  passwords, in this repository or in a fork.
* JupyterLab in Codespaces is started without a token because Codespaces
  already requires your GitHub login to reach the port. Keep forwarded port
  8888 **Private** (the default). Never switch it to Public.
